# QIP 2026

## Назначение
Современный веб-мессенджер в стилистике классического QIP.

## Текущая архитектура
- Backend: Node.js
- Основной сервер: `server.js`
- Клиент: `public/index.html`
- Дополнительная страница: `index.html`
- База данных: SQLite (`messenger.db`, не хранится в Git)
- Пользовательские файлы: `uploads/`, `public/uploads/` (не хранятся в Git)

## Реализовано
- Список контактов
- Статусы и X-статусы
- Отправка сообщений
- История сообщений
- Поиск по истории
- Отправка файлов
- Аватары
- Счётчик символов
- Цитирование сообщения по нажатию
- Мобильный интерфейс

## Правила веток
- `main` — стабильная версия
- `develop` — текущая разработка

## Правила разработки
- Не коммитить базу данных
- Не коммитить пользовательские загрузки
- Все изменения сначала делать в `develop`
- Перед изменениями проверять `git status`
