# QIP Messenger

Приватный мессенджер в стиле QIP 2005. Вход только по нику, без email/телефона.
Рассчитан на маленький круг (семья/друзья, до ~10 человек).

## Локальный запуск (проверить перед деплоем)

```bash
npm install
node server.js
```

Открой http://localhost:3210 в браузере.

## Деплой на твой Hetzner VPS

1. Залей папку на сервер (без node_modules — поставится заново):
   ```bash
   scp -r qip-messenger user@your-vps-ip:/home/user/
   ```

2. На сервере:
   ```bash
   cd qip-messenger
   npm install --production
   ```

3. Запуск через PM2 (как твой accounting-бот):
   ```bash
   pm2 start server.js --name qip-messenger
   pm2 save
   ```

4. По умолчанию слушает порт 3210. Если нужен другой:
   ```bash
   PORT=8080 pm2 start server.js --name qip-messenger
   ```

## Доступ извне (варианты)

- **Через Nginx reverse proxy** — проксируй домен/поддомен на localhost:3210,
  повесь HTTPS через Let's Encrypt (certbot). Так безопаснее и красивее с URL.
- **Просто по IP:порту** — быстрее для старта, но без HTTPS сообщения идут в открытом виде
  между устройством и сервером. Для семейного круга это разовый компромисс, но лучше
  всё же поставить Nginx + certbot, если сервер уже смотрит в интернет.

## PWA (иконка на экране телефона)

Пока это обычная веб-страница. Если нужно "как приложение" — добавляем
`manifest.json` + service worker, и на Android/iOS можно будет
"Добавить на главный экран" с иконкой и без адресной строки. Скажи, если это нужно.

## Что дальше можно добавить

- Групповые чаты (сейчас только 1-на-1)
- Пуш-уведомления (Web Push API) — чтобы приходило, даже когда вкладка закрыта
- Отправка фото/файлов (сейчас только текст)
- Индикатор "печатает..."
- Смена аватарки/эмодзи вручную (сейчас выдаётся случайно при регистрации)

## Структура проекта

```
qip-messenger/
├── server.js       # Express + Socket.io сервер
├── db.js           # SQLite схема (users, messages)
├── package.json
└── public/
    └── index.html  # Клиент (логин + список контактов + чат)
```

База данных `messenger.db` создаётся автоматически при первом запуске
в корне проекта — не забудь добавить её в бэкап на VPS, там вся переписка.
